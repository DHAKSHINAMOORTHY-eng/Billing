# SavoryBite — Premium Restaurant E-commerce Home Page

A modern, responsive, and colorful restaurant food delivery landing page built with **React** and **Tailwind CSS**.

## Features

- Sticky navbar with mobile menu
- Hero section with CTAs and stats
- Category browser (8 food categories)
- Product grid with ratings and add-to-cart
- Promotional offer banner
- Customer reviews
- Partner brands strip
- Full footer with newsletter signup

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Tech Stack

- React 18 + Vite
- Tailwind CSS 3
- Lucide React (icons)

## Project Structure

```
src/
├── components/     # UI sections (Navbar, Hero, etc.)
├── data/           # Mock data for products, reviews, etc.
├── App.jsx         # Main page composition
└── index.css       # Tailwind directives
```
